What is counted?

A count is added when the download API successfully records a YAML download request. It does not confirm a completed file transfer or represent a unique visitor. Repeat requests can count again. Direct file downloads, database outages, and requests above the recording budget are not included; HEAD, preflight, and marked prefetch requests are not counted.

No account or personal information is required. This tally stores only one aggregate counter per stance and uses no visitor identifiers, analytics cookies, or browser storage. Hosting providers may process request metadata in operational logs.
